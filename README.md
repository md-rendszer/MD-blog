# Máté Domokos archívum

A matedomokos.hu magyar nyelvű, Markdown-alapú statikus archívuma.

**Nyilvános webhely:** https://blog.mdmegvalositorendszer.hu/

A rendszer felépítéséről, a WordPress és a GitHub Pages összehasonlításáról, valamint az archívum statisztikáiról a [rendszerismertetőben](./_docs/README.md) olvashatsz. A változások összefoglalója a [változásnaplóban](./_docs/CHANGELOG.md) található.
