# Máté Domokos oldala

A matedomokos.hu magyar nyelvű, Markdown-alapú statikus archívuma.


A rendszer felépítéséről, a WordPress és a GitHub Pages összehasonlításáról, valamint az archívum statisztikáiról a [rendszerismertetőben](./documentation/README.md) olvashatsz. A változások összefoglalója a [változásnaplóban](./documentation/CHANGELOG.md) található.
