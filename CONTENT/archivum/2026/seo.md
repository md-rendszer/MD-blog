# 1. Nem kell újraírni a blogcikket

Ez fontos.

A Google **nem bünteti**, ha egy cikk nem volt eleve SEO-ra írva.

Amit csinálni kell:

✔ a cikk **címét javítani**  
✔ **alcímeket tenni bele**  
✔ **kulcsszavakat elhelyezni**  
✔ **meta leírást hozzáadni**  
✔ **képek ALT szövegét kitölteni**

Ez általában **5–10 perc egy cikknél**.

---

# 2. Telepíts egy SEO bővítményt (nagyon fontos)

A WordPress önmagában kevés SEO-hoz.

Menj ide:

**WordPress → Bővítmények → Új hozzáadása**

keresd meg:

### RankMath SEO

vagy

### Yoast SEO

Kezdőknek én inkább ajánlom:

👉 **RankMath**

Telepítés:

1. Bővítmények
2. Új hozzáadása
3. keresd: **RankMath**
4. Telepítés
5. Aktiválás

Utána a WordPress **lépésről lépésre végigvezet**.

---

# 3. Cikk címének javítása

Menj ide:

**WordPress → Bejegyzések → Szerkesztés**

A címet érdemes így alakítani:

Példa:

❌ rossz  
Amikor a szolga uralkodni kezd

✔ jobb

**Amikor a szolga uralkodni kezd – az ego és az emberi elme története**

Miért?

Mert benne van a kulcsszó:

**ego**

---

# 4. Permalink (URL) beállítása

A cikk alatt látod:

**Permalink**

Állítsd így:

❌ rossz

```
domain.hu/?p=123
```

✔ jó

```
domain.hu/ego-es-emberi-elme
```

vagy

```
domain.hu/amikor-a-szolga-uralkodni-kezd
```

Szabály:

✔ kisbetű  
✔ kötőjel  
✔ rövid

---

# 5. Alcímek használata (Google nagyon szereti)

A cikkben legyenek **alcímek**.

Példa:

### H2 alcímek

A spirituális hagyományok nézőpontja

A filozófia másik megközelítése

Az ego szerepe az ember életében

Egy egyszerű, de mély felismerés

WordPressben:

szöveg kijelölése → **Címsor (Heading 2)**

---

# 6. Kulcsszó megadása

Ha RankMath vagy Yoast van telepítve, a cikk alján lesz egy mező:

**Focus keyword**

Írd be:

```
ego
```

vagy

```
mi az ego
```

A plugin megmondja:

✔ mi jó  
✔ min kell javítani

---

# 7. Meta leírás (nagyon fontos)

Ez jelenik meg a Google találatok alatt.

A cikk alatt:

**Meta description**

Példa:

> Mi az ego és hogyan működik az emberi elmében? Spirituális és filozófiai gondolat arról, amikor az ego átveszi az irányítást az ember felett.

---

# 8. Képek SEO-ja

Ha képet töltesz fel:

WordPress → kép → **ALT text**

Írd be:

```
ego és emberi elme illusztráció
```

vagy

```
az ego mint jó szolga rossz uralkodó
```

Ez segít a Google-nek megérteni a képet.

# 10. Nagyon fontos: Google indexelés

Telepítsd ezt is:

### Google Site Kit

WordPress → Bővítmények → Új hozzáadása  
keresd:

**Site Kit by Google**

Ez:

✔ összeköti a weboldalt a Google-lel  
✔ megmutatja a látogatókat  
✔ elküldi a cikkeket a Google-nek

---

# 11. Egy nagyon fontos SEO szabály

A Google **nem a tökéletes cikkeket szereti**, hanem:

✔ rendszeres új cikkek  
✔ eredeti gondolatok  
✔ valódi tartalom

Ezért fontos:

**hetente 1 blogcikk**.

---

# Most mit csinálj konkrétan?

Sorban:

1️⃣ Telepítsd **RankMath SEO**  
2️⃣ Nyisd meg a blogcikket  
3️⃣ Javítsd a **címet**  
4️⃣ Adj hozzá **alcímeket**  
5️⃣ Írj **meta leírást**  
6️⃣ Adj meg **kulcsszót**  
7️⃣ Ellenőrizd az **URL-t**

Kész.
