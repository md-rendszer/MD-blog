# AISI logok

Ez a mappa a fejlesztési folyamat megosztható, összesített nyilvántartásának helye.

## Naplófájlok

- `sessions.md`: kizárólag az összesített session- és felhasználóiüzenet-szám.
- `sources.md`: külső források összesített jegyzéke.
- `tools.md`: használt eszközkategóriák és ellenőrzési módszerek.
- `research-log.md`: kutatási eredmények összefoglalója; ha nem történt kutatás, maradjon üres.

Ne ments ide session-exportot, egyedi felhasználói requestet, átiratot, azonosítót, helyi elérési utat vagy személyes adatot. A statisztikák kizárólag összesített formában szerepelhetnek az AISI reportokban.
