# AISI dev eszközök

Ez az összefoglaló az eszközök szerepét rögzíti; nem egyedi session vagy request log.

| Eszközkategória | Feladat |
| --- | --- |
| Fejlesztői környezet | Fájlok áttekintése és szerkesztése |
| Verziókezelés | Változások és kiadási előzmények követése |
| Szkriptek és automatizálás | Webhelyépítés, tartalomellenőrzés és képméretezés |
| AISI-asszisztensek | Dokumentációs és dev feladatok támogatása |
| Böngészők | A közzétett webhely megjelenítésének ellenőrzése |
