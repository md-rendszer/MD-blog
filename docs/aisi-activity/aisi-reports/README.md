# AISI reportok

Ez a mappa a projekt AISI-fejlesztésének kizárólag összesített statisztikáit tartalmazza.

## Fájlok

- `project-stats-totals.md`: a mutatók olvasható összefoglalója.
- `project-stats-totals.json`: ugyanennek a reportnak a géppel olvasható változata.

A két fájl ugyanazt az adatpillanatot írja le; egyik sem tartalmaz session-azonosítót, egyedi üzenetet vagy átiratot. Új összesítést mindkét formátumban frissíts, a megismételt számokat tartalmazó reportokat vond össze.
