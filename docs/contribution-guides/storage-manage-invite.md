# Közreműködői hozzáférés

A repóhoz hozzáférést a tulajdonos ad a GitHub **Settings** → **Collaborators** felületén. A meghívott a GitHub-értesítésben fogadja el a meghívást.

## Jogosultságok

- Olvasási jogosultság: a forrás és az előzmények megtekintése.
- Írási jogosultság: változtatások és branchek feltöltése.
- Adminisztrátori jogosultság: repóbeállítások és hozzáférések kezelése.

A szükséges legkisebb jogosultságot válaszd. A repóhoz való hozzáférés nem szükséges a blog olvasásához.
