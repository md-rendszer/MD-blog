# AISI-fejlesztői eszközök

Ez a rész az MD-blog fejlesztéséhez használt eszközökről ad rövid, repóspecifikus tájékoztatást.

- A webhelyépítő a Markdown-forrásból statikus oldalakat állít elő.
- A bejegyzés-ellenőrző a dátumokat, slugokat és helyi borítóképeket vizsgálja.
- A képfeldolgozó a borítóképek reszponzív AVIF-változatait készíti.
- A GitHub Actions munkafolyamat a `main` ágra érkező változásokat építi és telepíti.

A segédprogramok leírása és a pontos parancsok a [rendszerismertetőben](../../README.md) találhatók.
