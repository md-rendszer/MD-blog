# AISI-ügynöki munkakészségek

A repó gyökérkönyvtárának `.skills/` mappája tartalmazza a megosztott munkafolyamatokat. A Claude Code alatti megfelelő bejegyzések ezekre hivatkoznak, így ugyanaz az útmutató használható több AISI-környezetben.

| Készség | Rendeltetés |
| --- | --- |
| `tartalom-feltoltes` | Magyar oldal és bejegyzés létrehozása, valamint kért szöveg- és képmódosítás |
| `site-validation` | Statikus build és bejegyzés-ellenőrzés |
| `repo-audit` | Dokumentáció és projektútmutatók konzisztenciájának ellenőrzése |
| `changelog` | Kiadott és kiadásra váró változások dokumentálása |

Munkamenet-exportot, egyedi kérést vagy átiratot egyik készség sem hozhat létre a repóban.
