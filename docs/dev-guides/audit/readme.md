# Repóaudit

Az audit a projekt dokumentációjának, útvonalainak és közzétételi folyamatának konzisztenciáját ellenőrzi.

## Ellenőrzési pontok

- A README, az agent-útmutatók és a rendszerismertető az aktuális mappaszerkezetet írják le.
- A Pages-munkafolyamat az aktuális buildszkriptet és függőségi fájlt használja.
- A build és a bejegyzés-ellenőrző hiba nélkül lefut.
- A belső hivatkozások célfájljai léteznek.
- A `CONTENT/` fájlok csak kifejezett tartalmi kérés hatókörében módosulnak.
- Az AISI-jelentések kizárólag összesített, nem visszavezethető adatot tartalmaznak.

Az audit végén sorold fel az ellenőrzéseket, az eredményeket és a kihagyott pontokat.
