# Documentation

- Write visitor-facing system documentation and changelog entries in Hungarian.
- Keep agent guidance in `.agents/` in English and keep it specific to this repository.
- Use `documentation/README.md` as the system overview and `documentation/CHANGELOG.md` for released history.
- Record unreleased work in `documentation/changelog/unreleased.md`.
- Link to the canonical guide instead of copying long technical explanations into `README.md`.
- Changelog entries describe user-visible outcomes, not implementation details.
